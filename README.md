# Rule-Based Expert System

## Project Overview

This project implements a small rule-based expert system using Python.

The system accepts facts from the user and uses IF-THEN rules to infer new facts through forward chaining.

The system also supports multi-step inference and records the inference path so that the user can understand how the final conclusion was reached.

---

## Features

- Fact-based knowledge representation
- IF-THEN rule engine
- Forward chaining inference
- Multi-step rule chaining
- Inference/reasoning logging
- Interactive command-line interface
- Generic rule engine architecture
